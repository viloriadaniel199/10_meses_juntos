# Regalo de 10 meses

Experiencia romántica en español creada como regalo para “Mi lobita linda”.

## Cómo cambiar el contenido

- **Carta, frases, apodo y fecha:** están agrupados en `src/routes/index.tsx`. Busca `const letter`, `Mi lobita linda` y `Día 23`.
- **Fotos:** sube las nuevas imágenes al chat y pide reemplazar una foto concreta. Las actuales están en `src/assets/` como referencias seguras.
- **Canción:** cambia el título y el enlace de YouTube dentro de `src/routes/index.tsx`, cerca de “Nuestra canción”.
- **Colores:** la paleta completa está centralizada en `src/styles.css`, dentro de `:root`.

La música requiere un toque consciente y abre el video oficial; esto evita que un sonido inesperado arruine la sorpresa o sea bloqueado por el navegador.
